# EduNexoOS

## Sobre o projeto

O EduNexoOS é um projeto acadêmico voltado ao
estudo de Sistemas Operacionais e o desenvovilmento de uma melhoria para instituições educacionais.

## Objetivos

- Estudar o funcionamento do Linux.
- Compreender a arquitetura de sistemas.
- Documentar experimentos.
- Criação de um artigo científico.
- Ajudar em processor administrativos educacionais
